# Web Basics – Week 1

**Author:** Gayatri Kotwal

My first web page, built for the *Setup & Your First HTML Page* assignment.

## What's inside

| File | Purpose |
| --- | --- |
| `index.html` | My personal page: heading, short bio, hobbies list, an image and a link to my favourite website |
| `images/profile.svg` | Image shown on the page (stored in the repo so it always loads) |

## How to view it

1. Clone the repository and switch to this branch.
2. Open `index.html` in any web browser (or use the VS Code *Live Server* extension).

No build step or installation is needed.
